MUHAMMAD SUFYAN — PORTFOLIO DESIGN SYSTEM
==========================================
Theme: Dark, natural background + neon blue neural-network accent


1. BACKGROUND COLORS
---------------------

Radial glow center (hero):     #10141C
  → used as: radial-gradient(ellipse at 50% 30%, #10141C 0%, #0B0E14 70%)
Surface / card background:     #151A24
Card border (subtle):          rgba(56, 189, 248, 0.15)


2. FONT / TEXT COLORS
----------------------
Primary text (headings):       #E7EAF0   (soft warm white — never pure #FFFFFF)
Secondary text (subtext):      #8891A5
Body / list text:               #AEB4C2
Muted / footnote text:         #4A5266
Eyebrow / label text (accent): #38BDF8


3. NEON BLUE "SHINE" SYSTEM (the signature accent)
----------------------------------------------------
Core blue (accent, links, borders):    #38BDF8
Bright glow / pulse highlight:         #7DD3FC
Glow shadow (buttons, name highlight): rgba(56, 189, 248, 0.35) → 0.6 on hover
Node glow (canvas shadowBlur):         12–16px blur, color #7DD3FC or #38BDF8
Name highlight text-shadow:            0 0 24px rgba(56, 189, 248, 0.45)

Usage rule: keep neon blue on ACCENTS ONLY — buttons, links, icons, bullet
ticks, node/line animation, badges. Never use it as a body text color; body
text stays #AEB4C2 / #8891A5 so the blue keeps its "shine" instead of
becoming wallpaper.


4. NEURAL NETWORK BACKGROUND ANIMATION (Hero section signature)
-------------------------------------------------------------------
Canvas fill (clear each frame):    #0B0E14
Node count:                        ~55
Node radius:                       1–2.5px
Node fill:                         rgba(56, 189, 248, 0.75)
Node glow:                         shadowBlur 6px, shadowColor #38BDF8
Node movement:                     drift, velocity ±0.25px/frame, bounce off edges

Connection lines:
  - Draw only when two nodes are within 150px of each other
  - Line color: rgba(56, 189, 248, opacity)
  - Opacity scales with distance: (1 - dist/150) * 0.35
  - Line width: 0.6px

Pulse effect ("signal firing"):
  - ~2% chance per frame to spawn a pulse on a random active connection
  - Pulse travels from node A to node B over ~50 frames (t += 0.02)
  - Pulse dot radius: 2.5px, fill rgba(125, 211, 252, 0.9)
  - Pulse glow: shadowBlur 12px, shadowColor #7DD3FC


5. SIDEBAR / TIMELINE FIX (Experience section)
-------------------------------------------------
Problem: timeline line + circular markers were flush against the container's
outer edge, clipping against the black border instead of sitting inside it.

Fix:
  - Wrap timeline in a container with padding-left: 36px
  - Vertical line position: left: 11px (relative to timeline wrapper, not page edge)
  - Line color: linear-gradient(to bottom, rgba(56,189,248,0.5), rgba(56,189,248,0.08))
  - Line width: 1.5px
  - Circular markers: 24px diameter, background #10141C, border 1.5px solid #38BDF8
  - Marker center dot: 6px, fill #38BDF8, glow shadow 0 0 8px rgba(56,189,248,0.8)
  - Marker position: left: -36px (pulls it back onto the line, inside the padding)

Rule of thumb: any timeline / vertical-rule element should always sit inside
a padded wrapper — never positioned at 0 / flush with the outer container edge.
